## Incident: about 10–15 minutes of 404s on up to 12 URLs

The single all-in-one call returned a gateway error (405) but **kept running on the server**. It drafted the old posts
first, and before any replacement was published it had drafted 12 of them. For a while `/about/`, the About children,
`/about-our-group/`, `/materials/`, and the Adhesives, Glass, Kapton and Metal material pages returned 404. I recovered by
publishing in small batches (3–4 posts per call), broken URLs first, with guards that made each step idempotent with the
still-running request, whose target state is the same. **Lesson for next time:** no more than a few `wp_update_post`
calls per request on this host. Each takes about 3–10 s because of save hooks.
