# pages.txt — the page allow-list for a design zip (AUTOMATION.md §3a)
#
# Copy this file into the ROOT of the zip as `pages.txt`. When present it is the
# COMPLETE set of pages to build: anything not listed is not built, and no
# heuristic runs. Blank lines and #-comments are ignored.
#
# Format:  <path relative to zip root>[  <post_type>]
#   post_type is `page` (default), `post_services` or `post_application` —
#   nothing else (SKILL.md §1). Type follows what the page IS, because it sets
#   the permalink and the theme template: services go to post_services
#   (/services/<slug>/), application and sector pages to post_application.
#   Filenames contain spaces, so the type is read as the LAST token on the line;
#   if the last token isn't a post type, the whole line is the path.
#
# Drafts are created at pl-auto-<slug> and stamped _pl_auto_page = the path
# below, which is this page's durable identity across runs (AUDIT.md B5).
#
# ---------------------------------------------------------------------------
# Worked example: `Potomac Laser.zip` (origin/project-zip, 12,249,689 bytes)
# 23 HTML files in the zip; 11 are pages. Drafted 2026-08-06.
# ---------------------------------------------------------------------------
