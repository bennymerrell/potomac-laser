# Page manifest — which pages of a design zip get built (AUTOMATION.md §3a)
#
# This file lives in the REPO, not inside the zip: a re-export from Claude Design
# replaces the zip wholesale, and curation that lived inside it would be lost.
# Here it is version-controlled, reviewable in a diff, and survives re-exports.
#
# BINDING — the coordinator matches a zip to its manifest by these two directives.
# `zip:` (filename) is authoritative; `zip_sha256:` is advisory. If the hash has
# moved but the filename still matches, the manifest is USED and the run reports
# "manifest predates this zip revision — re-check for new pages".
#
# zip: Potomac Laser.zip
# zip_sha256: fab7225ce0879014418672228148420215c3a39fa6463bea2012d2ce7b798db9
# pattern_cap: 20
#   Raised from the default 8 (AUTOMATION.md §7.9) on 2026-09-24: RUN A's ten pages need
#   ~20 new section shapes. Run 20260924-100754 minted 7 and failed 8 pages on the budget;
#   the zip is `partial`, so the next run re-enters only those 8 pages, with this cap.
#
# Format:  <path relative to zip root>[  <post_type>][  interactive=<file>][  was=<old path>]
#   post_type is `page` (default), `post_services` or `post_application` —
#   nothing else (SKILL.md §1). Type follows what the page IS, because it sets
#   the permalink and the theme template: services go to post_services
#   (/services/<slug>/), application and sector pages to post_application.
#   Filenames contain spaces, so key=value fields are pulled out first, then the
#   type is read as the LAST remaining token; if that isn't a post type, the
#   whole remainder is the path.
#
#   interactive=<file> names a SELF-CONTAINED interactive cluster already in
#   wp-content/uploads/novamira-drafts/ (AUTOMATION.md §3.c.iv). The abbreviated
#   filenames cannot be derived from the design filename, which is why they are
#   declared here. The run REFERENCES these files and never modifies them.
#
#   was=<old path> carries a page's identity across a RENAME in a re-export.
#   The identity check (AUTOMATION.md §3.c.i) looks up _pl_auto_page = the path
#   first, then = the was= path. A hit on either is the same page, so a renamed
#   file is recognised as already built instead of being drafted a second time.
#   Paths contain spaces, so was= takes the rest of the line after it and must
#   come LAST.
#
# This list is COMPLETE: anything not listed is not built. Any HTML file in the
# zip that is missing from this list is REPORTED as unlisted, so a re-export that
# adds pages cannot be silently dropped.
#
# Drafts are created at pl-auto-<slug> and stamped _pl_auto_page = the path
# below, which is this page's durable identity across runs (AUDIT.md B5).
#
# ---------------------------------------------------------------------------
